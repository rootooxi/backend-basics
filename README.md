# Backend Basics

Учебный проект для знакомства со структурой Python-проекта.

## Требования

Python 3.12.x

## Запуск

В папке проекта создай виртуальное окружение и установи зависимости. Команды для PowerShell в Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```
